### 🌐 Network Addressing & Subnet Architecture  




This repository includes detailed documentation for:

- Private IP address pools  
- CIDR notation  
- Subnet masks  
- Network IDs  
- Broadcast addresses  
- Usable host ranges  
- Allocation strategies  

#### Example: CIDR /24  
- Subnet: `/24`  
- Mask: `255.255.255.0`  
- Network ID: `NNN.NNN.NNN.0`  
- Broadcast: `NNN.NNN.NNN.255`  
- Total IPs: `256`  
- Usable IPs: `254`
